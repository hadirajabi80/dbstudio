# Rowlit 1.3.0

## New
- **Saved queries in a schema** (like Navicat's Queries). Save a console's query with a name into a database/schema
  (Ctrl+Alt+S, or the console's Save menu); it appears in a **Queries** folder under the schema in the explorer and as
  a **Queries** type in the Objects tab. Double-click to open; the console stays bound to the saved query, so Ctrl+S
  updates it in place. Rename (F2), duplicate, copy SQL and delete from the context menu; Ctrl+P finds saved queries
  (type `q:` to list only queries).
- **Small icons view** in the Objects tab: icon + name tiles, many per row, next to List and Cards.

## Fixed
- **New procedure / function / package / trigger:** Ctrl+S now creates the object in the database instead of opening
  the Windows "Save SQL file" dialog. The name is read from the script (rename it in the template if you like); after
  the first save the tab becomes an "Edit:" console, where Ctrl+S saves changes and Run executes the routine.
- **Name check when creating:** saving or running a new object's script is refused when an object with that name
  already exists (instead of silently replacing it with CREATE OR ALTER / CREATE OR REPLACE); the New wizard warns while
  you type the name.
- **Upgrading from DbStudio:** if the first Rowlit start missed your DbStudio data (for example when DbStudio had been
  started from a packaged app such as a terminal inside another app), Rowlit now finds it and moves it over on the next
  start, as long as you have not saved new connections in Rowlit yet. The log says why a data folder was chosen.
