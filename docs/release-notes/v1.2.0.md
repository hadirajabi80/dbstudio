**DbStudio is now Rowlit.** Same app, same features, a new name and a new icon. *See your data in a better light.*

## What changes

- **New name and icon.** The app, its windows, menus, installer, shortcuts and notifications are now called
  **Rowlit**. The new icon shows three table rows with the middle one lit up, and it is the same mark in the title
  bar, on the welcome screen and in Settings.
- **Your connections and settings carry over automatically.** On its first start Rowlit moves your DbStudio data
  folder to the Rowlit one: saved connections and passwords, settings, query history, ER diagram layouts, filters and
  your open tabs with unsaved text. On macOS your saved passwords stay in the Keychain where they are.
- **The new repository** is [github.com/hadirajabi80/rowlit](https://github.com/hadirajabi80/rowlit). Links to the old
  address keep working.
- Exported Excel files, generated code and the application name that servers show for your sessions (SQL Server,
  Oracle, PostgreSQL, MongoDB, Redis, Kafka) now say Rowlit. Connections you saved with a custom application name or
  client id keep it.

## New

- **Find in database (Ctrl+Shift+F).** Search object names, columns, code (procedures, functions, views, triggers)
  and optionally table data. The scope follows what you selected in the explorer: a connection, database, schema, a
  type folder or specific tables, or every connected connection when nothing is selected, and you can change it in the
  scope picker. Results stream in grouped by object with highlighted matches; opening one jumps to the matching line,
  column or row.
- The grid's "Quick filter by the focused cell" moved to **Ctrl+Alt+F**.

## Upgrading from DbStudio

**Windows:** DbStudio 1.1.0 updates itself to Rowlit like any other update (or run the installer yourself). The
upgrade replaces DbStudio in place: the old app and its "DbStudio" shortcuts are removed, Rowlit is installed in
`%LOCALAPPDATA%\Programs\Rowlit` with new "Rowlit" shortcuts, and Apps & Features lists **Rowlit**. If you pinned
DbStudio to the taskbar, pin Rowlit again.

**macOS:** you'll get an "Update available" notice in DbStudio. Download the DMG, drag **Rowlit** to Applications,
quit DbStudio and start Rowlit; once it has started, drag **DbStudio** from Applications to the Trash. If DbStudio is
still running, Rowlit asks you to quit it first, so your data is never split between the two.
