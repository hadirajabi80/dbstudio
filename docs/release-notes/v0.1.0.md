First public release of **DbStudio**: a fast, keyboard-first desktop client for **SQL Server, Oracle and SQLite**, with DataGrip-class IntelliSense.

## Highlights

- **IntelliSense that understands your SQL**: alias, CTE and subquery aware completion, foreign-key JOIN suggestions (`JOIN Orders o ON o.CustomerId = c.Id`), INSERT column lists, signature help, hover, F12 to definition, live diagnostics.
- **Multiple connections at once**: every tab has its own connection and database; run one query on several connections.
- **Results grid**: streams 100k+ rows smoothly, type-aware formatting, copy as CSV/TSV/JSON/Markdown/SQL, export.
- **Professional filtering**: typed operators, AND/OR groups, quick filter from a cell, push the filter to the server, saved filters.
- **Edit data like Navicat**: edit cells, insert and delete rows, save with Ctrl+S in one transaction.
- **Code formatter** for procedures, functions, packages and scripts (keeps comments): Ctrl+Alt+L or Shift+Alt+F.
- **Designers**: create and alter tables, views, procedures and triggers visually, with a DDL preview; F4 edits existing objects.
- **Code generation**: C#, Go, TypeScript, Java and Python from tables, views, procedures and queries.
- Query plan viewer, snippets and postfix templates, query parameters, history, Ctrl+P go to any object, command palette, light/dark themes.

## Install notes

- **Windows**: the installer is not code-signed yet, so SmartScreen shows "Windows protected your PC". Click **More info → Run anyway**.
- **macOS**: the app is not notarized yet. After dragging it to Applications, right-click **DbStudio → Open** the first time, or run:
  `xattr -dr com.apple.quarantine /Applications/DbStudio.app`
- Data (connections, history, settings) lives in `%APPDATA%\DbStudio` on Windows and `~/Library/Application Support/DbStudio` on macOS. Passwords are encrypted with DPAPI (Windows) or stored in the Keychain (macOS).

## Known limitations

- SQL Server and Oracle support is covered by unit and golden tests but has not yet had a release smoke test against live servers.
- PostgreSQL support is planned for the next release.
