# Rowlit 1.2.1

## New
- **Objects tab.** A permanent first tab, like Navicat's, that follows the explorer: select a connection to see its
  databases and schemas, a schema to see its tables, or a Procedures/Functions/Views folder to see those. It updates
  in the background without taking you away from your console, remembers the type filter per schema, and has a
  breadcrumb to walk back up. Turn it off in Settings › General.
- **Find in database is now a dialog.** Ctrl+Shift+F opens a centred search window with search-as-you-type for
  names, columns and code, a preview of the matching code, ↑/↓ to move and Enter to open. Reopening it brings back
  your last search; "Open in tab" keeps the results as a tab.

## Fixed: Oracle table editing
- Tables without a primary key can now be edited (by ROWID, like Navicat and SQL Developer), in the data tab and for
  `SELECT t.*, ROWID FROM t` in a console.
- Saving rows of tables with CLOB/NCLOB/BLOB columns no longer fails with ORA-22848 when "verify unchanged values" is on.
- No more false "row was changed" conflicts on BINARY_FLOAT columns and very long NUMBER values (which are no longer
  rounded); Oracle's empty string = NULL is handled.
- Columns named after reserved words (COMMENT, MODE, …) save correctly.
- Identity columns (GENERATED ALWAYS) are read-only in the grid.
- Tables in other schemas, and restored data tabs, are editable again.
- The table designer keeps lower-case (quoted) table, column and view names instead of upper-casing them (ORA-00942).

## Changed
- The grid's "Quick filter by the focused cell" is Ctrl+Alt+F (Ctrl+Shift+F is Find in database).
- With the Objects tab on, an empty workspace opens on it instead of a new console.
