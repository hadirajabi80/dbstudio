**DbStudio 1.0** is a fast, keyboard-first desktop database client for Windows and macOS.

## DbStudio at a glance

- **Databases:** Microsoft SQL Server, Oracle, PostgreSQL and SQLite, plus workspaces for Redis, MongoDB and Kafka.
- **SQL editor:** schema-aware IntelliSense, live diagnostics, formatter, snippets, manual transactions, parameters and query plans.
- **Results grid:** streams hundreds of thousands of rows smoothly, with filters, a value viewer, copy in many formats and export.
- **Objects:** explorer, table designer, object editing with Compare with server, code generation and an ER diagram that stays smooth with 500+ tables.
- **Server logs and activity:** server logs, sessions, locks and blocking chains, side by side with your queries.
- **Keyboard first:** every action is in the command palette (Ctrl+Shift+P), Ctrl+P jumps to any object, and F1 opens the shortcut sheet.
- **Updates itself:** on Windows the app installs new versions on its own; on macOS it tells you when one is available.

## New since 0.2.2

### Editing database objects

- **Ctrl+S saves to the database.** In an "Edit:" console (F4 on a view, procedure, function or trigger), Ctrl+S applies the script to the server, refreshes the explorer and resets Compare with server. **Save as…** still writes a `.sql` file.
- **Save button** on the toolbar of edit consoles. A dot shows when there are unsaved changes.
- **Execute procedure or function…** opens a dialog with one input per parameter. Each parameter has a NULL toggle, and **Default** where the routine has one. A live preview shows the call, and **Last values** refills the previous run. In a routine's edit console, Run becomes **Execute…**, and its menu still has **Run script**.
- **New setting:** *Open procedures and functions in edit mode* (Settings › Editor). Double-click, Enter and Ctrl+P then open routines ready to edit, not as a read-only definition.

### IntelliSense and the editor

- **Redesigned suggestion list:** clearer kind icons and colours, more readable rows sized to the editor font, and the last row is never cut off.
- **Schemas and databases appear in suggestions,** including `db.`, `schema.` and `db.schema.` chains. A schema whose objects are still loading shows "Loading…" instead of an empty box.
- **Ctrl+Space always works:** it re-opens a stuck or empty suggestion box, and works from the toolbar and the results. Ctrl+I does the same on keyboard layouts where Ctrl+Space is taken.
- **Ctrl + mouse wheel** (⌘ + wheel on macOS) zooms the text in any SQL editor, including Compare. The size is saved as Settings › Editor › Font size.
- **Snippets** in Settings are coloured like the editor, with their tab stops marked.

### Results

- **Copy query** under every result table: copy the statement behind the grid with its values filled in, copy it with its parameters, or open it in a console.
- **Persian, Arabic and Hebrew** values read right-to-left in result grids, the record view, filters, history, logs and the Redis, MongoDB and Kafka views. Text that starts in English stays left-to-right.

### Look and feel

- **Official provider logos** for every database, on the welcome screen, in connections, the explorer and tabs.
- **Shortcut sheet:** hold Ctrl, Alt or Shift to see the shortcuts that use them, or press a key combination to find what it does.
- **Quieter scrollbars,** and the Compare view has one scrollbar per side instead of stacked change rulers.
- **Welcome screen:** more even spacing around the keyboard hints.

### Reliability

- **A crash stays in its area.** If one tab, panel, dialog or settings section fails, only that area shows an error panel with a way to recover. The rest of the window keeps working, and you no longer get a blank window.
