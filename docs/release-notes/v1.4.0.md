# Rowlit 1.4.0

Six new databases, with the same console, explorer, Objects tab, IntelliSense and tools as the existing ones.

## New databases
- **MySQL and MariaDB** — console with `DELIMITER` scripts, multiple result sets, server warnings and fast cancel
  (`KILL QUERY`); explorer with procedures, functions, triggers, events and sequences; table designer (renames, column
  order, prefix and generated columns, auto-increment); data editing; `EXPLAIN FORMAT=JSON` / `EXPLAIN ANALYZE`
  (MariaDB `ANALYZE`); dependencies; error, general and slow logs, InnoDB status and an activity view with Kill.
- **ClickHouse** — console with `KILL QUERY` cancel and exact big numbers; Array/Map/Tuple/JSON in the grid; tables,
  materialized views, dictionaries and functions; MergeTree-aware designer; EXPLAIN with index use; query log, running
  queries, mutations and merges; a Parts & partitions view.
- **Snowflake** — password, key pair, browser SSO and OAuth sign-in; switch warehouse, role, database and schema from
  the console; catalog browsing without waking a warehouse; `GET_DDL`; EXPLAIN and operator statistics; query history,
  warehouse load, running queries and locks; stages, streams, tasks, pipes and file formats.
- **Elasticsearch and OpenSearch** — cluster overview, index browser (documents, mappings, settings, aliases, shards,
  stats), document editing with conflict protection, a query DSL editor with completion and an aggregations viewer, a
  Kibana-style Dev Tools console, SQL, tasks, and reindex / import / export jobs with progress.
- **Cassandra and ScyllaDB** — CQL console with IntelliSense and cqlsh commands (`CONSISTENCY`, `TRACING`, `DESCRIBE`,
  `PAGING`), paged results, a tracing timeline, keyspaces, tables, materialized views, UDTs and functions with
  partition/clustering keys, table designer, editing by primary key, and a cluster view.

Every new database has a ready-to-run sample in `engine/tests/docker` (the same "shop" data as the others, Persian
text included); Snowflake has a walkthrough for a free trial account in `docs/qa/snowflake-walkthrough.md`.

## Also
- IntelliSense for the new dialects loads only when you open a connection that needs it, so startup stays as fast as
  before.
- New provider logos on the Welcome screen and in the explorer.
