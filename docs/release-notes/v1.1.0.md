# DbStudio 1.1.0

## New
- **Objects page**: a Navicat-style list of every table, view, procedure, function, trigger and sequence in a database or schema, with type filters and counts, live search, sortable rows/size/modified/comment columns and a card view. Open it from the explorer ("Show objects", Enter or double-click on a database, schema or folder) or the command palette.
- **Dependencies**: a new section in every object tab shows what the object uses and what uses it (foreign keys, tables, views, routines, triggers), grouped, with click-through and "Open in ER diagram".
- **Execute procedures and functions without opening them**: a redesigned dialog with typed inputs (numbers, dates, switches), NULL/Default toggles, validation and a live SQL preview. Results open on a full-page result tab with OUT parameters and the return value as a card, one tab per result set and collapsible messages. Consoles get a maximize/restore button for the results pane.
- **Split editor and detached windows**: drag a tab to an edge to split the editor side by side or stacked, drag between groups, or open a tab in its own window and move it back.
- **Themes**: seven app colour themes (Light, Paper, Solarized Light, Dark, Midnight, Nord, Violet) and eleven code themes, chosen independently.
- **Excel export** (.xlsx) from results and data tabs, with typed cells, a frozen bold header and auto filter.
- **Settings redesign**: icons, search, grouped cards, theme previews and a fixed dialog size.
- **Updates**: download progress in the status bar, "Check for updates" in Settings, and a notification when a new version is available or ready.

## Fixed
- IntelliSense now offers the schemas (including dbo/public/main) and databases of the current connection near the top, and lists databases after `USE`.
- Ctrl+S on a procedure saves the whole object even when text is selected, and no longer refreshes the explorer tree.
- SQL Server ER diagrams on old or permission-restricted databases show relationships again (foreign keys to tables the login cannot see, keys from other schemas, role-owned schemas); disabled keys are drawn dotted.
