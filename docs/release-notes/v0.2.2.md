A small polish release on top of 0.2.1 (auto-update, glass title bar).

## Improved

- **Empty table view:** a table with no rows now shows a table icon in a soft accent circle, "No rows yet", the table's name, and an **Insert row** button when the table is editable. Before, it showed a filter icon and "The table is empty", which looked like a filter problem.
- **"No rows match" view:** same style, with a short hint and **Clear filter**.
