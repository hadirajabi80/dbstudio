A polish release, and the first one that **updates itself**.

## New

- **Auto-update.** DbStudio checks GitHub Releases shortly after it starts and every 6 hours.
  - **Windows:** the update downloads in the background, then "DbStudio X.Y.Z is ready — Restart now / Later" appears. Choosing Later installs it the next time you quit.
  - **macOS:** you get an "Update available" notice with a download link. Silent updates on macOS need a signed app, which this build isn't yet.
  - "Check for Updates…" is in the Help menu and the command palette, and Settings has a switch to turn automatic checks off.
- **Glass title bar.** On Windows 11 the top bar uses the native Mica material and holds the window controls, like VS Code and Windows Terminal; the menu is under ☰. macOS gets title-bar vibrancy. Windows 10 shows a solid bar.

## Improved

- **Focused editor:** a slim accent stripe on its left edge replaces the heavy frame around the whole editor.
- **Search box:** "Ctrl P" (⌘P on macOS) appears as one soft hint with a lighter border.
- **macOS shortcuts:** the Redis, MongoDB and Kafka screens now show ⌘ in their tooltips and hints.
- **CI:** more robust on slower runners. The macOS Kafka native-library check now passes; it was failing because of a mistake in the check, not in Kafka.
