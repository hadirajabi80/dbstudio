# ClickHouse keyboard-only walkthrough (plan-batch3 WP-CH)

Goal: the daily loop on ClickHouse without the mouse, with focus never lost. Run it twice:

1. **Mock**: `npm --prefix ui run dev:mock`, open `http://localhost:5173/?fresh` (another port with `npx vite --mode mock --port 5285`),
   connection **ClickHouse Shop** (folder "Batch 3"; `clickhouse-dev`, database `shop`). The mock serves the SQLite shop tables
   under the ClickHouse id plus the ClickHouse extras and the parts / mutations / merges routes with moving fake data.
2. **Docker**: `docker compose -f engine/tests/docker/compose.yml up -d clickhouse` (seed `seed-clickhouse.sql`), a live engine,
   and a new connection to `localhost` port `18123` / database `shop` / user `shop` / password `shop`.

Shortcuts are written for Windows; on macOS read Ctrl as ⌘. Window 1280×800; repeat steps 1–8 at 1024×680. Rows marked
*(R3)* depend on a shared change requested in `docs/wp-notes/WP-CH.md`; until it lands they behave as noted.
